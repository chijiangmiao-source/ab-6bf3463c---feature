# 硅像素读出板 · 奇偶校验噪声故障定位

录入 **2–36 个唯一通道**与至多 **28 条奇偶校验**（每条引用非空、互不
重复的通道集合及观测奇偶值），系统求出使全部 XOR 约束同时成立的
**最小汉明重量故障向量**；重量相同时按通道标识升序形成的选择向量做
标准字典序裁决。提交后立即得到请求标识并显示求解进度，完成后得到
复核编号；结果返回前可取消并在同页立即提交另一份观测。刷新页面可凭
复核编号取回故障通道、选择向量与逐校验复算结果。无可行解释时保存
**不可行结论**，不返回任何近似集合。

## 算法（折半综合征索引 + 两侧候选精确合并）

通道按标识排序后折半（左 `l = n//2`，右 `n-l`，n≤36 时每半至多
2¹⁸ 个部分向量）：

1. 枚举左半全部部分向量，以综合征（引用该半区故障通道的校验奇偶
   组合，紧凑为一个 int）为键建立索引，每键保留重量最小、同重量
   选择向量字典序最小的候选；
2. 右半按重量层枚举，精确查找所需左半综合征 `sL = target XOR sR`，
   合并两侧候选并按 `(总重量, 完整选择向量字典序)` 裁决；
3. 右半重量层严格超过已知最优重量后剪枝。

算法**不枚举完整 2ⁿ 故障向量、不使用随机搜索、不以高斯消元的任意解
替代最优解**；两侧合并是精确的，故结论即为全局最优。

## 复核与请求生命周期

合法提交立即（`202`）获得**请求标识**与**输入摘要**，求解在后台
进行，页面轮询请求状态与进度；完成后才分配复核编号。

- `POST /api/submit`：`{"channels": [...], "checks": [...], "request_id"?: "..."}`
  - 缺省 `request_id` 时服务分配 32 位十六进制标识；客户端也可自带
    8–64 位 `[A-Za-z0-9_-]` 标识用于网络重传去重。
  - 服务在**开始求解前**完成校验、冻结排序通道与校验集合，并持久化
    `pending → running → done | cancelled | failed` 状态与计算进度。
  - **相同标识 + 相同输入**的重传（含求解中的并发重传）始终返回
    同一请求状态，不会重复求解。
  - **复用标识却改变输入**返回 `409`，错误定位在 `request_id`。
- `GET /api/request/<请求标识>`：取回状态、进度、输入摘要与
  （完成后）复核编号及结论。
- `POST /api/cancel`：`{"request_id": "..."}`。求解在折半枚举与
  左右候选合并的**确定检查点**（每 4096 个部分向量及重量层边界）
  响应取消；**取消的请求不生成复核编号、不写入复核记录**。
  完成与取消竞争时，以持久化的条件更新裁决，只收敛为一个终态。
- `GET /api/review/<复核编号>`：已完成请求刷新后取回提交内容、
  最小故障通道与逐校验复算。
- 非法输入返回 `400`，`errors[].field` 为可定位字段（如
  `channels[2]`、`checks[0].channels`、`checks[0].parity`），不保存
  请求或复核记录；页面保留编辑内容并清除旧证据。

页面上结果返回前可随时取消，并在同页立即提交另一份观测：每个请求
只显示自身的进度与结论，旧计算即使稍后结束也不会覆盖页面或写入
复核记录；页面分别呈现计算、已取消、拒绝与完成状态。

复核记录与请求状态持久化在命名卷 `locator-data`（容器内
`/data/locator.db`）。

## verify 服务

```bash
docker compose up --build verify
```

`verify` 服务对唯一故障、多解裁决、不可行用例运行代码测试
（`tests/test_solver.py`，含确定检查点取消）与接口测试
（`tests/test_api.py`，含取消后重提、相同输入并发重传、标识冲突、
完成/取消终态裁决），执行字节码构建检查（`compileall`），并对运行中
的 `app` 服务做 API 冒烟（`tests/smoke_api.py`：健康检查、异步提交与
轮询、取消后重提、相同输入并发重传、标识冲突 409、完成记录刷新、
不可行持久化、可定位拒绝）。全部通过后退出并返回 `0`；任一步失败
返回非零码。

本地不使用 Docker 时也可直接运行（仅需 Python 3.11 标准库）：

```bash
python tests/test_solver.py
python tests/test_api.py
APP_DB=/tmp/l.db python app/server.py
APP_URL=http://127.0.0.1:8080 python tests/smoke_api.py
```
